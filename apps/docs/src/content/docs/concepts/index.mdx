Worker Static Assets は SPA を配信し、`/api/*` を Worker に渡します。R2 は private、D1 は正本、Queue は非同期通知、Vectorize は派生 index です。構成図と検索制限は [処理・検索の設計](./index-and-search.mdx)、失敗復旧と deployment invariant は [本番構成](./production-mapping.mdx) にまとめています。
