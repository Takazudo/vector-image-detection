---
title: AI 語と人間タグ
description: provenance、変更権限、正規化、検索上の扱い
sidebar_position: 3
---

AI suggested words は Workers AI vision run の出力です。モデル出力は信頼せず、parse、Unicode/空白正規化、重複除去、長さ/件数制限をして保存します。caption と model ID、prompt/document version が provenance です。

human tag は匿名利用者が attach/remove できる別データです。同じ正規化ルールを使い、空・長すぎ・重複・上限超過を拒否します。tag mutation は同一 D1 transaction で tag、document revision、`reindex_required_revision`、outbox を更新します。AI word の作成・削除・書換えには使えません。

古いオフライン CLI の vocabulary propagation や `localStorage` tag は hosted app の data model ではありません。検索で同じ写真に複数の一致があっても、human tag が AI word と related より常に強い理由になります。
