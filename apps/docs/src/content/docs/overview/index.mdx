このプロジェクトのホスト済みアプリは、公開書き込みを有効にしたときだけ匿名利用者が写真をアップロードし、人間のタグを付けられる写真ライブラリーです。既定は読み取り専用です。

<Warning>
  公開書き込みを有効にすると匿名アップロードと匿名タグ編集を受け付けます。元画像は再エンコードしないためメタデータが残ることがあります。自動モデレーション、審査キュー、通報機能はありません。問題のあるコンテンツは運用者が後から
  purge するだけです。
</Warning>

アップロードは private R2、正本は D1、非同期処理は Queue/DLQ、説明文・AI 語・埋め込みは Workers AI、派生検索ベクトルは Vectorize に置きます。詳しくは [できることと限界](./what-it-does.mdx) と [処理・検索の設計](../concepts/index-and-search.mdx) を参照してください。
