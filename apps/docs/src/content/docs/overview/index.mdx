Vector Image Detection は、フォルダー内の未整理な写真をベクトル化し、言葉や似た写真で探せるようにする TypeScript 製の PoC です。電気部品、在庫、現場写真など、ファイル名やタグだけでは見つけにくい写真の山を対象にしています。

ローカルの SigLIP モデルで画像を 768 次元のベクトルに変換するため、通常の検索・類似検索・語彙による分類は API キーなしで実行できます。まずは [モックのクイックスタート](/docs/getting-started/mock-quickstart) で画面と流れを、次に [実モデルのクイックスタート](/docs/getting-started/real-model-quickstart) で品質を確かめてください。
