---
title: 公開デモの写真で試す
description: コミット済みのライセンス表示付き実写真を使ってデモを確認する
sidebar_position: 2
---

Node.js 22.12 以上と pnpm 10 を用意し、リポジトリのルートで実行します。

```sh
pnpm install
pnpm build
pnpm demo:fixture
pnpm demo:dev
```

表示された URL（通常は `http://localhost:5173`）を開きます。`demo:fixture` はコミット済みの fixture bundle を `apps/demo/public/data/` にコピーします。

この bundle には 100 枚の実写真（Oxford-IIIT Pet 60 枚、Wikimedia Commons の電子部品 40 枚）が含まれます。`manifest.json` と `CREDITS.md` に各写真の出典、作者（提供される場合）、ライセンスを保持しています。

ギャラリーと類似写真はすぐに使えます。検索、語彙タグ、分類を初めて実行すると、ブラウザが SigLIP のテキストモデル（約 100 MB）をダウンロードし、その後はキャッシュを使います。
