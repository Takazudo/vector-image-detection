---
title: ローカル検証
description: 資格情報なしでビルド、D1 migration、Worker の契約を確認する
sidebar_position: 2
---

```sh
pnpm install
pnpm build
pnpm typecheck
pnpm --filter @vector-image-detection/docs run check
pnpm test:scripts
pnpm --filter @vector-image-detection/demo run db:migrate:local
pnpm --filter @vector-image-detection/demo run test:worker
pnpm --filter @vector-image-detection/demo run test:dom
pnpm run cloudflare:dry-run
```

`wrangler.jsonc` は `PUBLIC_WRITES_ENABLED: "false"` のローカル構成です。Worker の D1/R2/Queue 契約と provider fake は確認できますが、資格情報なしの run は live D1/R2/Queue/Workers AI/Vectorize の互換性を証明しません。AI/Vectorize の実サービス smoke test は provisioning 後の保留作業です。

`/api/v1/readiness` は安全な構成状態を返しますが、外部 binding は deferred と表示します。認証済み `/api/v1/operator/readiness` だけが production binding、migration、モデル、Vectorize index、acknowledgement を検査します。
