最初に画面とデータ経路だけを確認するならモック、実際の検索品質まで確認するなら実モデルを選びます。両方ともリポジトリのルートで実行します。

モックの結果は意味的な品質を示しません。実写真を扱う前に、[実モデルとサンプル写真](/docs/getting-started/real-model-quickstart) のモデルダウンロード、データ取得、費用・ネットワーク条件を確認してください。
