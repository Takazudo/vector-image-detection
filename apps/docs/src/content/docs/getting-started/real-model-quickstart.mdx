---
title: オフライン CLI 実験
description: ローカル SigLIP と Qdrant を使う既存ツール（ホスト済みアプリとは別）
sidebar_position: 3
---

```sh
pnpm build
pnpm vis ingest ./photos --index inventory
pnpm vis search "blue connector with six pins" --index inventory
pnpm vis similar ./example.jpg --index inventory
```

`vis` はローカル SigLIP embedding、ローカル bundle、任意の Qdrant を使います。画像対画像検索、語彙 tag、見本伝播、ブラウザーモデルの仕組みは、この Cloudflare ライブラリーの related 検索や公開 UI の機能ではありません。外部 VLM と Qdrant の注意点は [CLI と外部連携](../guides/vlm-and-qdrant.mdx) を参照してください。
