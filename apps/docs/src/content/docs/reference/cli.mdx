title: Cloudflare コマンド
description: local/remote を取り違えないための build、migration、dry-run、preflight

| 目的                       | 実行するコマンド                                                                                         | remote への作用                    |
| -------------------------- | -------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| local D1 migration         | `pnpm --filter @vector-image-detection/demo run db:migrate:local`                                        | なし                               |
| docs 構文/リンク           | `pnpm --filter @vector-image-detection/docs run check`                                                   | なし                               |
| docs build                 | `pnpm --filter @vector-image-detection/docs run build`                                                   | なし                               |
| local credited seed import | `pnpm run demo:seed:local`                                                                               | なし（local D1/R2 test resources） |
| placeholder deploy dry-run | `pnpm --filter @vector-image-detection/demo run deploy:dry-run:production`                               | なし                               |
| remote D1 migration        | `pnpm exec wrangler d1 migrations apply <d1-name> --remote --config apps/demo/wrangler.production.jsonc` | 指定 D1 のみ                       |
| authenticated release gate | `pnpm run cloudflare:demo-preflight`                                                                     | readiness GET のみ                 |
| rendered demo deployment   | `pnpm --filter @vector-image-detection/demo run deploy`                                                  | 指定 production Worker             |

`--remote` を含む D1 command と明示した resource name は実 account に作用します。production name を shell history、issue、docs、source にハードコードしません。`wrangler vectorize create <name> --dimensions=768 --metric=cosine` の metric/dimension は作成後に変更できないため、モデルの 768-dimensional embedding と一致することを先に確認してください。

`cloudflare:demo-preflight` は `DEMO_PREFLIGHT_URL`、`DEMO_PREFLIGHT_TOKEN`、3 acknowledgement variables を必要とします。ready response は configuration、D1、migrations、R2、Queue、DLQ、Workers AI、Vectorize、rate limit、operator acknowledgements をすべて `pass` と報告する必要があります。

`pnpm run demo:seed:local` は 100 credited thumbnails を deterministic local D1/R2/outbox import に通し、ready/attribution と unchanged rerun を確認します。`node apps/demo/scripts/seed-manifest.mjs [--remote --target <environment>]` は validation/report 専用で Cloudflare に書き込みません。`--remote` に `--target` がなければ失敗し、remote を暗黙選択しません。local seed command は remote target を明示的に拒否します。remote seed は provision 後の authenticated operator action として deferred です。

offline CLI の正確な options は `pnpm vis <command> --help` を正本とします。`vis` の command は hosted release workflow ではありません。
