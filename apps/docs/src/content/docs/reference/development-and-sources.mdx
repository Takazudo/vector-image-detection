## Release/preflight 向けの focused checks

```sh
pnpm --filter @vector-image-detection/docs run check
pnpm --filter @vector-image-detection/docs run build
node --test scripts/cloudflare/demo-preflight.node-test.mjs
pnpm --filter @vector-image-detection/demo run db:migrate:local
pnpm --filter @vector-image-detection/demo run deploy:dry-run:production
```

preflight tests は acknowledgement、production environment、public writes、pinned models、すべての required binding check を検証します。docs build/check はナビゲーションと MDX を検証します。dry-run は placeholder/構文を検証します。これらは live provider smoke test ではありません。

## Deferred live verification

resources を provision した後に、最小権限 token と production target を使って実行・記録します。

- `/api/v1/operator/readiness` の D1 migration/model metadata、private R2、Queue/DLQ、Workers AI binding、Vectorize 768/cosine、rate limit、acknowledgement。
- 一つの upload が R2 → D1/outbox → Queue → AI → generation-stamped vector → ready まで進むこと。
- exact human、exact AI、related と、AI/Vectorize 障害時の exact-only warning。
- retention/purge が R2、全 vector generation、D1 を retryably 削除すること。

provisioning 前はこれらを pass と宣言しません。
