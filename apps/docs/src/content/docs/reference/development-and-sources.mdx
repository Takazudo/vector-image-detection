## 開発チェック

```sh
pnpm install
pnpm typecheck
pnpm test
pnpm build
pnpm format
```

通常のテストはオフラインで実行できます。実モデルのテストは `RUN_MODEL_TESTS=1`、実際の VLM 呼び出しを行う live test は `RUN_VLM_LIVE=1` と API キーが必要です。VLM の live test は費用と外部送信を伴うため、意図して実行してください。

ドキュメントだけを確認するには次を使います。

```sh
pnpm --filter @vector-image-detection/docs run check
pnpm --filter @vector-image-detection/docs run build
```
